# results/

Raw sweep artifacts, one directory per run, never overwritten. What each
file is, which record schema a run carries, and which runs the Canary
Register is built from: [`docs/reference/results-layout.md`](../docs/reference/results-layout.md).

These are data, not a leaderboard. `completions.jsonl` files carry the
providers' raw responses, reasoning traces included; see
[`docs/CONTAMINATION.md`](../docs/CONTAMINATION.md) before republishing.
